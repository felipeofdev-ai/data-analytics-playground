\# Data \& Analytics Playground



This repository contains practical examples of \*\*data analysis and ETL\*\* using Python, Pandas, NumPy, Matplotlib, and SQL (SQLite).  

It demonstrates fundamental skills in data manipulation, visualization, and database integration.



---



\## 📚 Topics Covered



\- Loading and cleaning datasets (CSV, SQL)  

\- Basic ETL (Extract, Transform, Load)  

\- Data analysis with Pandas and NumPy  

\- Data visualization with Matplotlib  

\- SQL queries with SQLAlchemy

## ⚙️ Setup

1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/data-analytics-playground.git
cd data-analytics-playground

Create a virtual environment

python -m venv venv
.\venv\Scripts\activate   # Windows PowerShell
# source venv/bin/activate  # Linux/Mac

Install dependencies

pip install -r requirements.txt

Running the ETL

python scripts/etl_process.py

Running SQL Queries

python scripts/sql_queries.py

Jupyter Notebook

jupyter lab notebooks/data_analysis.ipynb

Explore the data, statistics, and visualizations interactively.
